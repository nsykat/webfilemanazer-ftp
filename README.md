# Web File Manager & FTP

A lightweight, web-based file manager and FTP interface that allows users to manage files, directories, and server connections seamlessly through a clean browser interface.

## 🚀 Features

* **Web-Based File Management:** Navigate, view, upload, download, rename, and delete files directly from your browser.
* **FTP Integration:** Connect to remote FTP servers to manage your files remotely.
* **Modern Interface:** Built with a responsive and intuitive layout using HTML, JavaScript, and PHP.
* **Lightweight & Fast:** Minimal setup required with zero heavy database dependencies.

---

## 🛠️ Tech Stack

* **Frontend:** JavaScript, HTML5
* **Backend:** PHP

⚙️ Installation & Setup
Clone the Repository:

Bash
git clone [https://github.com/nsykat/webfilemanazer-ftp.git](https://github.com/nsykat/webfilemanazer-ftp.git)
Host on a Local/Remote Server:

Place the project directory inside your web server's root folder (e.g., htdocs for XAMPP or /var/www/html for Apache/Nginx).

Ensure your server supports PHP.

Access the Application:

Open your browser and navigate to your local or server path (e.g., http://localhost/webfilemanazer-ftp/).
